# Claude Lifeboat v0.1.5 — start with Windows

> Paste this into the GitHub release body for the `v0.1.5` tag.

The fleet's gorgeous new look comes to Lifeboat, plus a friendly startup toggle.

### New look

- **Elevated Claude-brew dashboard.** The status page is now frosted glassmorphism over a soft aurora — glass cards, gradient drive-usage bars, tinted status badges, and an automatic dark mode that follows your OS.

### Added

- **Run at startup.** A new **"Run at startup"** toggle in the tray menu pins the Lifeboat tray to your per-user Windows startup (no admin, no UAC), so the buoy reappears when you log in. It controls the *tray* only — your automatic backups run on their own schedule whether the tray is open or not.
- **Real release packaging** (`tools\Build-Release.ps1`) — builds a clean, versioned `claude-lifeboat-v<version>.zip` plus a SHA256 checksum, containing only what an end user needs. The version is read from `src\lifeboat.ps1`, so there's a single source of truth.

### Changed

- The one-line installer now **prefers a packaged release asset** when one is attached, falling back to GitHub's source archive for older releases.
- The tray icon is now a proper **life-ring** glyph (outer ring + coral hub + four lashings), so Lifeboat is easy to tell apart from the other fleet tools at a glance. It still doubles as a status light (green / amber / red / grey).
- README: added an honest **"How it differs from the alternatives"** section.

### Get it

One line in an Admin PowerShell:

```
irm https://github.com/JackBhanded/claude-lifeboat/raw/main/install.ps1 | iex
```

Or download the release zip and double-click **`Install Claude Lifeboat.bat`**.
